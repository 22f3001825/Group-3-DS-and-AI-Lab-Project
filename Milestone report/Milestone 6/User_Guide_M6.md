
# Milestone 6 — User Guide

Summary: Step-by-step instructions and examples for end users to run and interact with the system, both locally and on the deployed demo. Includes troubleshooting tips and recommended workflows.

## Quick Start (Local Developer Demo)
1. Create and activate a Python virtual environment.
	- Windows: `python -m venv .venv` then `.venv\Scripts\activate`
	- macOS / Linux: `python3 -m venv .venv` then `source .venv/bin/activate`
2. Install Python dependencies:

```bash
pip install -r requirements.txt
```

3. Start the backend API (development):

```bash
uvicorn src.api.main:app --reload --port 8000
```

4. Start the frontend (from `web/`):

```bash
cd web
npm install
npm run dev
```

Open `http://localhost:5173` (or the port shown) to access the demo UI.

## Using the Deployed Demo
1. Open the deployment URL provided in the README.
2. Pick a preset example from the Examples dropdown to see sample behavior.
3. Or upload a file (.md, .txt, or .pdf). For PDFs, use the `scripts/pdf_to_text.py` helper first if available.
4. Type a question and press `Ask`.

## Walkthrough Example
- Upload: `data/cleaned/faq/week03_faq.md`.
- Ask: "How does backpropagation work?"
- Expected flow: system shows a 2–3 sentence answer and below it, the exact chunk(s) it used from the document with links to open the full source.

## Interpreting Results
- Answer: concise text generated by the LLM.
- Source passages: snippets displayed below the answer — click to view full context.
- Confidence indicators: when available, the UI shows a relevance score for the top retrieved passages.

## Common Troubleshooting
- If the UI is blank: ensure backend is running at `http://localhost:8000`.
- If uploads fail: check file size limits and that the preprocessing script supports the file type.
- Poor answers: try rephrasing the question or reduce chunk size so context is more focused.

## Advanced: Using the API
- Query endpoint: `POST /api/query` with payload `{ "text": "<your question>", "top_k": 5 }`.
- Upload endpoint: `POST /api/upload` with multipart form-data containing the file.
